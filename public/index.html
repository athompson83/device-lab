How iOS works here

iOS and its simulator only execute on Apple hardware — that's an Apple licensing/architecture restriction, not a Windows limitation. Device Lab streams a real iOS simulator running in the cloud (Appetize.io) into this panel: you interact with it exactly like the Android emulator, and file bugs into the same tracker. "iOS emulators for Windows" found on the web are fakes.

1 · Connect Appetize (free tier)

Create a free account at appetize.io, copy your API token from Account → API, paste it here. It is stored only in this app's local data folder.

2 · Get an iOS build

An iOS app must be compiled on macOS. For a GitHub repo, add this workflow — GitHub's free macOS runners build the simulator .app and hand you a zip artifact to upload below.

3 · Upload & run (.zip of .app, or .ipa)
